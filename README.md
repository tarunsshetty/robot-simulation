This is a Robot simulation project I built. It creates an AI pathway around obstacles, allowing the robot to find the shortest distance to its target to the robot.This is an interactive web-based simulation that demonstrates advanced AI pathfinding algorithms in action. It showcases how a programmed agent can intelligently navigate around, dynamically calculate the shortest path, and maneuver around obstacles to reach its target destination.
Features:
- Angular pathfinding implements intelligent algorithms to autonomously find the most efficient route.
- Dynamic obstacle navigation: the AI recalculates paths in real time when faced with obstacles.
- Interactive grid: users can place and adjust grid cells to test different scenarios and challenges.
- Responsive web interface built using modern web technologies for a smooth visual experience.
Technologies used:
- HTML5
- CSS3
- JavaScript
- ESX+
